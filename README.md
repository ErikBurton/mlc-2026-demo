# Music Lessons Central — redesign demo

Static HTML/CSS, no build step. Upload the contents of this folder to a GitHub repository and turn on GitHub Pages (Deploy from a branch → main → / root).

Before going live:
- Remove the `<meta name="robots" content="noindex, nofollow">` line from every page.
- Copy `favicon.ico` from the current site into this folder.
- Add back the Google Analytics tag if the school still wants it.
